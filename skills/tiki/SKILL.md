# Tiki tickets

Before ticket work, run `tiki skill` and follow the returned instructions. They match the installed CLI and cover authentication, commands, pagination, and safe recovery from failed writes. Reuse them for the workflow; read them again after updating the CLI.

Use the installed `tiki` executable or the binary path supplied by the user. If unavailable, report that the CLI needs installing; do not initialize a database or start a new server to find existing tickets.
